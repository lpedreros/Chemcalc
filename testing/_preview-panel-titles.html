Dark-panel titles: before and after

Each page shows its dark-panel title three ways, side by side, in the real box with the real text. Before is exactly how the live page renders it today. After is the proposed .mp-panel-title, the same as the “Industries I’ve built for” heading on services.html. After, in white is the same size with the color left white, so you can judge size and color separately. The numbers under each label are read from the browser’s computed style for that exact heading, at your current window size. No live page uses the new class yet.
